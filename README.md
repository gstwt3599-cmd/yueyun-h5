## 二、怎么跑起来

### 方式 1：直接双击（最快）

用浏览器打开 `index.html` 即可。纯静态、零依赖、零构建，`file://` 下也能正常跑。

### 方式 2：本地起服务（推荐，手机可扫码）

在本目录下执行：

```bash
python -m http.server 8000
```

然后电脑访问 `http://127.0.0.1:8000/index.html`；
手机连同一个 WiFi，访问 `http://<电脑局域网IP>:8000/index.html`。

### 方式 3：生成二维码

```bash
python make_qrcode.py                 # 自动取本机局域网 IP，生成 qrcode.png
python make_qrcode.py --port 8080     # 换端口
python make_qrcode.py --url https://你的域名/yueyun-h5/index.html   # 部署后生成正式二维码
```

二维码生成器是**纯 Python 实现**（`qrcode_pure.py`），不需要装任何第三方库；
如果环境里装了 `qrcode` 库会自动优先使用它。
`qrcode.png` 可直接贴到课件、海报、答辩 PPT 上，扫码即进页面。

### 方式 4：部署到线上

把 `yueyun-h5` 整个文件夹上传即可（GitHub Pages / Gitee Pages / 校园服务器 / 对象存储都行），
**不需要构建步骤**。部署后用 `make_qrcode.py --url <线上地址>` 重新生成二维码。

## 四、匹配算法怎么算的

1. **六道性格维度**（每题选项都带维度权重）：
   | 维度 | 含义 | 主要指向 |
   |---|---|---|
   | A | 气场与担当 | 文武生 |
   | B | 才情与审美 | 小生 |
   | C | 温度与亲和 | 正印花旦 |
   | D | 机趣与应变 | 丑生 |
   | E | 韧劲与锋芒 | 二帮花旦 |
   | F | 掌控与分寸 | 武生 |

2. **两步归一化**（关键，否则结果会严重偏科）：
   - ① 按维度在问卷中的出现总量归一，避免「考得多的维度」系统性压倒别的维度；
   - ② 按每个行当的「理论最高得分」归一，保证六根柱子起点一致。

3. **决胜规则**：前两名分差小于 1% 时，看第一题的选择更贴近谁。

参数（`alpha = 0.2`、副路线权重、`reach` 归一化）是经过 6×4×4 组网格搜索选定的。
用 20000 次均匀作答 + 每个行当 4000 次定向作答做过校验，结果：

- 均匀作答下六柱占比：丑生 20.2% / 小生 18.7% / 正印花旦 17.9% / 文武生 17.0% / 二帮花旦 14.4% / 武生 11.8%
- 定向作答命中率：正印花旦 92.0%、丑生 92.0%、小生 90.6%、二帮花旦 89.1%、文武生 84.5%、武生 74.7%

想改题目或调整偏向，只改 `js/data.js` 里的 `QUESTIONS` 与 `DIM_TO_ROLE` 即可，
`js/quiz.js` 会自动按新数据重新归一化。

## 五、出场动画怎么做的

- 每个行当一套**关键帧**（`js/character.js` 的 `CHOREO`），关键帧之间做缓动补间；
- 姿态用 `T(侧, 手位x, 手位y, 手法偏转)` 生成：内部用两段式手臂反解
  （`ikReach`）算出上臂 / 前臂角度，所以「手放在哪里」是所见即所得的，
  不会出现手臂翻到头顶的情况；
- 舞台层（追光、光尘、地台倒影、落地涟漪）与人物层解耦，可以单独换；
- **换成真实美术素材时**：只需替换 `drawFigure()` 内部的绘制，
  或者把整块 canvas 换成序列帧 / Lottie 动画，`createCharacterStage()` 的对外接口不用变。

目前人物是**几何剪影风格**（长袍 + 水袖 + 头面 + 把子），刻意做得简洁，
方便后面接美术同学画的素材。正式版建议：真人实拍抠像 → 序列帧，或请美术出 SVG。

## 七、已知限制

- 出场动画是几何剪影，不是写实美术，**定位是「示意 + 占位」**；
- 问卷结果存在 `localStorage`，清理浏览器数据会丢；
- 二维码默认指向局域网地址，**必须手机与电脑同一 WiFi** 才能扫码访问；
  对外发布请用 `--url` 换成线上地址重新生成；
- `_preview.html` / `_big.html` / `_geo.html` 是内部校对页，发布时可以删掉。
