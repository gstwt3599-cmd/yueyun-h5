# 粤韵新声 · 粤剧行当互动 H5

> 北京理工大学（珠海）大学生创新创业训练计划项目
> 《粤韵新声——香山文化视域下非遗粤剧艺术的数字化传播与创新实践》

**线上地址：** https://gstwt3599-cmd.github.io/yueyun-h5/

这是项目申报书中「互动 H5 页面」这一项的可运行雏形（v0.1），对应预期成果里的
「粤剧文化互动 H5 页面 1 个」。

## 这是什么

一个手机上打开的互动页面，用「六柱制」这个粤剧行当体系当入口，让没看过粤剧的年轻人
先通过一次测试认识行当，再顺着看动画、读故事、学妆造、认识名家。

| 板块 | 页面 | 内容 |
|---|---|---|
| ① 六柱制角色测试 | `quiz.html` | 12 道题，测出你对应哪个行当 |
| ② 角色出场动画 | `role.html` | Canvas 绘制的登场小动画，六个行当各一套动作 |
| ③ 角色前世今生 | `role.html`「前世今生」 | 每个行当「从哪里来 / 今天什么模样」 |
| ④ 妆造搭配知识 | `makeup.html` | 通用基础 5 讲 + 六柱逐个对照 + 日常借鉴 |
| ⑤ 名家荟萃 | `masters.html` | 唐涤生、红线女、马师曾、薛觉先 |

## 怎么看

**线上（推荐）**：手机或电脑直接打开 https://gstwt3599-cmd.github.io/yueyun-h5/

## 怎么改内容（组内同学看这里）

**99% 的改文案需求，只需要改一个文件：`js/data.js`。** 不用碰逻辑，也不用碰 HTML。

| 想改什么 | 在 data.js 里找 |
|---|---|
| 六个行当的名字、标语、关键词 | `ROLES` |
| 行当的「前世今生」短文 | `ROLES[].past` / `ROLES[].now` |
| 行当的妆造要点、日常借鉴 | `ROLES[].styling` |
| 问卷题目和选项 | `QUESTIONS` |
| 妆造知识（通用基础） | `MAKEUP_BASICS` |
| 名家介绍 | `MASTERS` |

⚠️ 改 `QUESTIONS` 的选项权重（`w` 字段）会影响匹配结果，其余字段随便改。
如果只是改文案、不增删题目，权重完全不用动。

**改完怎么上线**：把改动同步到 `_deploy` 目录并推送（详见项目根目录的《操作说明》）。

## 匹配算法（给想了解原理的同学）

**六道性格维度**，每题选项都带维度权重：

| 维度 | 含义 | 主要指向 |
|---|---|---|
| A | 气场与担当 | 文武生 |
| B | 才情与审美 | 小生 |
| C | 温度与亲和 | 正印花旦 |
| D | 机趣与应变 | 丑生 |
| E | 韧劲与锋芒 | 二帮花旦 |
| F | 掌控与分寸 | 武生 |

**两步归一化**（关键，否则结果会严重偏科）：
1. 按维度在问卷中的出现总量归一，避免「考得多的维度」系统性压倒别的维度；
2. 按每个行当的「理论最高得分」归一，保证六根柱子起点一致。

**决胜规则**：前两名分差小于 1% 时，看第一题的选择更贴近谁。

参数（`alpha = 0.2`、副路线权重、`reach` 归一化）经 6×4×4 组网格搜索选定。
用 20000 次均匀作答 + 每个行当 4000 次定向作答校验，结果：

- 均匀作答下六柱占比：丑生 20.2% / 小生 18.7% / 正印花旦 17.9% / 文武生 17.0% / 二帮花旦 14.4% / 武生 11.8%
- 定向作答命中率：正印花旦 92.0%、丑生 92.0%、小生 90.6%、二帮花旦 89.1%、文武生 84.5%、武生 74.7%

## 出场动画（给想换美术的同学）

- 每个行当一套**关键帧**（`js/character.js` 的 `CHOREO`），关键帧之间缓动补间；
- 姿态用 `T(侧, 手位x, 手位y, 手法偏转)` 生成，内部用两段式手臂反解（`ikReach`）
  算出关节角度，所以「手放在哪里」是所见即所得的；
- 舞台层（追光、光尘、地台倒影、落地涟漪）与人物层解耦，可单独替换。

**目前是几何剪影风格**，刻意做得简洁，就是为了后面接美术素材。
换素材时只替换 `drawFigure()` 内部的绘制，或者整块 canvas 换成序列帧 / Lottie，
`createCharacterStage()` 的对外接口不用变。

## 后续可以做的

1. **换美术**：剪影 → 美术绘制立绘 / 真人实拍序列帧，加音效配乐（注意自动播放限制）；
2. **扩内容**：每个行当目前 2 段短文，可扩成「行当小传 + 代表剧目 + 经典唱段」；
3. **香山本土 IP**：唐涤生已在名家页，下一步可加「唐家湾文化地图」「唐涤生剧目年表」；
4. **数据回收**：目前结果只存浏览器本地。做推广时可加提交接口，回收成传播分析的原始数据；
5. **分享裂变**：加「生成我的行当海报」（canvas 导出图片），便于朋友圈 / 小红书传播；
6. **横屏适配**：目前竖屏优先；要投屏展示的话需补一套横屏布局。

## 已知限制

- 出场动画是几何剪影，定位是「示意 + 占位」，不是最终美术；
- 测试结果存在浏览器 `localStorage`，清缓存会丢，也没有联网回收；
- GitHub Pages 在国内部分网络下访问可能偏慢。
